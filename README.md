# PD信号和DDS输出振幅同步与否验证器

一个简单的 Windows 桌面测试工具，用于反复遮光/放光时，同时观察：

- 示波器 CH1：PD→ADC→FPGA→DAC 链路输出的平均电压 `VAVG`
- 示波器 CH2：DDS/VCO RF 输出的峰峰值 `VPP`

通过两条时间曲线可以直接判断PD信号变化与DDS输出振幅变化是否同步。

## 界面

程序只保留四个操作按钮：

- 开始
- 停止
- 清空
- 导出

上图显示CH1 `VAVG`，下图显示CH2 `VPP`。顶部显示两路当前读数；图表自动缩放并显示最近300个数据点。

## 硬件连接

1. 示波器CH1连接要观察的DAC/PD链路输出。
2. 示波器CH2连接DDS/VCO RF输出。
3. 在示波器上打开CH1和CH2，并手动调好量程、时基和触发。
4. RIGOL DS1102Z-E通过USB Device或LAN连接电脑。

## 运行

Windows下双击：

```text
启动CH1-CH2时间监测.cmd
```

然后点击“开始”，反复遮光和放光，观察两条曲线是否同时变化。

程序每次生成并冻结一个新帧，再从同一个冻结帧读取CH1 `VAVG`和CH2 `VPP`，避免把不同采集帧的数据配成一个点。

如缺少PyVISA，先运行：

```text
安装依赖.cmd
```

## 数据导出

停止监测后点击“导出”，生成的CSV包含：

- 时间戳
- 相对时间/s
- CH1 VAVG/V
- CH2 VPP/V

## 运行环境

- Python 3.10+
- Tkinter
- PyVISA 1.13+
- RIGOL DS1102Z-E
