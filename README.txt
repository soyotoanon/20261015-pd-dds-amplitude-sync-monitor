CH1 / CH2 随时间监测
====================

用途：反复遮光/放光时，观察两路示波器测量值随时间是否同步变化。

显示：
  上图：CH1 VAVG（平均电压，单位 V）
  下图：CH2 VPP（峰峰值，单位 Vpp）

使用：
  1. 在 RIGOL DS1102Z-E 上打开 CH1 和 CH2，并手动调好量程、时基和触发。
  2. 示波器通过 USB Device 或 LAN 连接电脑。
  3. 双击“启动CH1-CH2时间监测.cmd”。
  4. 点击“开始”，程序会自动寻找并连接示波器。
  5. 反复遮光/放光，观察上下两条时间曲线。
  6. 点击“停止”后可导出 CSV。

程序每次冻结一个新帧，再从同一帧读取 CH1 VAVG 与 CH2 VPP。
